서비스 소개
무엇을 하는 서비스인가
"은행 연동 없이. 가입 없이. 바로 시작."
스크린샷 한 장이면 AI가 구독을 자동으로 찾아냅니다.

SubTrackr는 구독 서비스 통합 관리 플랫폼입니다. Netflix, Spotify, ChatGPT 등 흩어진 구독들을 한 화면에서 추적하고 월별 지출을 파악할 수 있습니다. 가장 큰 차별점은 은행 계좌 연동 없이 영수증·카드 명세서 스크린샷만으로 AI가 구독을 자동 감지한다는 점입니다. 회원가입도 불필요하며 전체 무료입니다.

운영사는 주식회사 헬로브이알(HelloVR)이며, 130개 이상의 서비스와 11개 언어를 지원하고 광고 수익으로 운영됩니다.

✓
데이터 이식성 보장 JSON · CSV 내보내기·가져오기 제공. 앱이 사라져도 데이터를 잃지 않는다는 신뢰 제공.

SEO 중심 블로그 전략 "넷플릭스 해지 방법", "스트리밍 비교" 등 검색 수요 높은 콘텐츠로 자연 유입 창출.

개선 제안
보완 가능한 영역
!
메시지 일관성 문제 "가입 없이 시작"이라고 하면서 우상단에 "로그인" 버튼이 존재. 신규 방문자에게 혼란을 줄 수 있음. "데이터 동기화를 위해 로그인 선택 가능" 등 문맥 설명 필요.
!
광고 UI 영향 페이지 하단 광고 배너가 앱 경험을 저해할 수 있음. 광고 위치나 포맷 최적화로 UX와 수익을 동시에 챙길 여지 있음.
!
기기 간 동기화 불명확 데이터가 로컬에 저장된다면 기기를 바꾸거나 여러 기기 사용 시 데이터 유실 우려. 동기화 방식을 랜딩에서 명확히 설명할 필요.
!
네이티브 앱 부재 구독 알림은 모바일 앱에서 더 자연스러움. 웹 전용 서비스의 한계로 결제 D-day 알림 기능이 제한될 수 있음.
!
자동 갱신 감지 부재 은행 연동을 안 하는 대신 새 구독이 자동으로 추가되지 않음. 주기적으로 스크린샷을 찍어야 하는 사용자 행동 비용 존재.
!
소셜 증명 부족 사용자 수, 별점, 후기 등 신뢰 지표가 랜딩에 없음. "X만 명이 사용 중" 같은 수치가 전환율을 높일 수 있음.
